# mondex-mirror
Static read-only backup snapshot of https://monaf.ai (mondex), refreshed daily by `wget --mirror` and published to https://blockchains.github.io/mondex-mirror/.
The live app uses SSR, server functions, auth and a database, so this mirror is view-only: logins, server actions and live data will not work. Source: Blockchains/mondex (private).
